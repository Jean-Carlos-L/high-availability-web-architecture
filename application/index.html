Página de ejemplo del Reto 2.

En el reto real, esta página la sirve nginx en cada instancia EC2, detrás de un Application Load Balancer.

Consulta user-data.sh: genera dinámicamente una versión que muestra el ID y la Availability Zone de la instancia que responde, para verificar el balanceo.

Puedes reemplazar esta página por tu propia aplicación.
